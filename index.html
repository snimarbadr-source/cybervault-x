خطوات النشر

الملف README.md داخل الـ zip فيه الشرح الكامل.

  1. GitHub: ارفع كل الملفات إلى مستودع جديد.
  2. Vercel: Add New → Project → اختر المستودع → Deploy (بدون أي إعدادات).
  3. قاعدة البيانات: من مشروعك في Vercel → Storage → Create → Upstash Redis (مجاني) → Connect Project، ثم Redeploy.
  4. اختياري GitHub Pages: Settings → Pages → Branch: main، ثم ضع رابط Vercel في الخانة بالأعلى.
بدون تسجيل دخول، أي شخص يعرف رابط موقعك يستطيع رؤية حساباتك. احتفظ بالرابط سرياً، أو فعّل VAULT_KEY في Vercel لإضافة رمز وصول يُطلب مرة واحدة لكل جهاز.
