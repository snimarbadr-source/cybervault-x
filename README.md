# CyberVault X — خزنة الحسابات الشخصية

خزنة حسابات **بدون تسجيل دخول**، تعمل على **Vercel** و **GitHub Pages**،
وتظهر فيها نفس الحسابات على أي جهاز.

## محتويات المشروع
| الملف | وظيفته |
|---|---|
| `index.html` / `style.css` / `app.js` | الموقع نفسه |
| `intro.js` | المقدمة السينمائية (5 ثوانٍ ثم تنفتح بوابة الخزنة) |
| `config.js` | إعداد رابط الخادم (مهم فقط لـ GitHub Pages) |
| `api/vault.js` | الخادم (Vercel Function) الذي يحفظ الحسابات |
| `vercel.json`, `package.json`, `.nojekyll` | ملفات إعداد |

## النشر على Vercel (الطريقة الأساسية — تعمل كل الميزات)
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه **كل محتويات** المجلد (داخل `cybervault-x`، وليس المجلد نفسه).
2. في Vercel: **Add New → Project** → اختر المستودع → **Deploy** (بدون تغيير أي إعداد).
3. بعد النشر افتح مشروعك في Vercel ← **Storage** ← **Create Database** ← اختر **Upstash Redis** (الخطة المجانية تكفي)
   ← **Connect Project**. سيضيف Vercel المتغيرات تلقائياً.
4. اذهب إلى **Deployments** ← ⋯ ← **Redeploy**.
5. افتح الموقع: يجب أن تظهر في أعلى الصفحة شارة خضراء **«متزامن سحابياً»**. تمّ.

## النشر على GitHub Pages
GitHub Pages يستضيف ملفات ثابتة فقط (لا يملك خادماً)، لذلك يحتاج رابط Vercel ليحفظ الحسابات:
1. أنجز خطوات Vercel أعلاه أولاً.
2. في المستودع: **Settings → Pages → Branch: main / (root) → Save**.
3. افتح موقع GitHub Pages ← تبويب **الإعدادات والنشر** ← ضع رابط Vercel (مثل `https://my-vault.vercel.app`) ← **حفظ ومزامنة**.
   (أو عدّل `API_BASE` في `config.js` مرة واحدة فيعمل على كل الأجهزة دون إدخال يدوي.)

بهذا يظهر نفس المحتوى سواء فتحت رابط Vercel أو رابط GitHub Pages.

## ⚠️ ملاحظة أمنية مهمة
لأنه لا يوجد تسجيل دخول، **أي شخص يعرف رابط موقعك أو رابط الـ API يستطيع رؤية حساباتك**.
- احتفظ بالرابط سرياً ولا تشاركه.
- للحماية الإضافية دون حساب: في Vercel ← Settings ← Environment Variables أضف `VAULT_KEY` بقيمة سرية ثم Redeploy.
  سيطلب الموقع الرمز **مرة واحدة فقط لكل جهاز** ثم يتذكره.
- كلمات السر تُخزَّن كنص عادي في قاعدة البيانات؛ لا تحفظ فيها حسابات بنكية حساسة جداً.

## التشغيل المحلي للتجربة
افتح `index.html` مباشرة: سيعمل بوضع «محلي» (الحفظ في هذا الجهاز فقط) حتى تربطه بخادم.
